# 💰 Expense Tracker

> **Python Internship — Project 2 @ DecodeLabs**

A simple GUI-based **Expense Tracker** developed using **Python and Tkinter** to record expenses and monitor total spending.

## 🚀 Features

- ➕ Add expenses
- 📝 Add expense description
- 💵 Enter expense amount
- 📋 View expense history
- 🔢 Track total spending
- 🗑️ Delete selected expense
- 🧹 Clear all expenses
- ⚠️ Input validation
- ✅ Confirmation dialogs
- ⌨️ Keyboard support

## 🛠️ Technologies

- Python 3
- Tkinter
- MessageBox
- Python Lists
