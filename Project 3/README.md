# 🔐 VaultKey – Random Password Generator

A secure and user-friendly **Random Password Generator** developed in Python as part of the **DecodeLabs Python Programming Internship – Project 3**.

The project includes both a **Command-Line Interface (CLI)** and a modern **Graphical User Interface (GUI)** version.

## 🚀 Features

* Generate strong random passwords
* Custom password length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters
* Password strength indicator
* Copy password to clipboard
* Show / hide password
* Clear generated password
* Input validation
* Keyboard shortcut support
* User-friendly dark-themed GUI

## 🖥️ Versions

### 1. CLI Version

A simple terminal-based password generator that allows users to:

* Enter password length
* Generate secure passwords
* Generate multiple passwords
* Validate user input

### 2. GUI Version – VaultKey

A modern Tkinter-based graphical version featuring:

* Dark-themed interface
* Custom password settings
* Strength indicator
* Copy button
* Show / Hide functionality
* Generate and Clear controls
