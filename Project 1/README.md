Python To-Do List Application
A simple menu-driven To-Do List application developed using Python as part of my internship project at DecodeLabs.

Project Overview
This project is a console-based To-Do List application that allows users to manage their tasks through a simple menu-driven interface.

The application provides options to add tasks, view saved tasks, and exit the program.

Features
Add new tasks
View all saved tasks
Display tasks with numbering
Simple and interactive menu
Handles empty task lists
Exit option
Concepts Used
Python Lists
While Loop
If / Elif / Else
User Input
append()
enumerate()
Basic Program Flow
How It Works
The program continuously displays a menu with three options:

Add a Task
View Tasks
Exit
When a user adds a task, it is stored in a Python list.

When the user chooses to view tasks, the application displays all saved tasks with their corresponding numbers.

The program continues running until the user selects the exit option.
