# ✅ To-Do List Application

> **Python Internship — Project 1 @ DecodeLabs**

A simple To-Do List application developed using **Python**, with both **CLI** and **GUI (Tkinter)** versions.

## 🚀 Features

- ➕ Add tasks
- 📋 View tasks
- 🗑️ Delete selected tasks
- 🧹 Clear all tasks
- 🔢 Task counter
- ⌨️ Enter key support
- ⚠️ Input validation and confirmation dialogs

## 🛠️ Technologies

- Python 3
- Tkinter
